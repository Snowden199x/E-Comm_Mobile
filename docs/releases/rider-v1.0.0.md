# Vendo Rider 1.0.0

First public Android build of the Vendo Rider app.

**Download:** `vendo-rider.apk` below (universal, works on 32-bit and 64-bit phones).
**Requirements:** Android 7.0 (API 24) or newer.
**Size:** 107 MB universal. A 46.6 MB `app-arm64-v8a-release.apk` is attached for 64-bit phones.

## What's inside

- Rider sign-in with email/password, approved rider accounts only.
- Transport Driver accounts can sign in from the same form; an approved driver opens the trips screen.
- Assigned pickups and deliveries, QR/Code 128 scanning, delivery proof with photo, COD amount to collect.
- Notifications, accrued earnings and cash on hand.
- Package `vendoph.rider`, version 1.0.0 (versionCode 2).

## Install

1. Tap the APK on your phone (or scan the QR on the Vendo Logistics landing page).
2. Allow "Install unknown apps" for your browser when Android asks.
3. Open **Vendo Rider** and sign in with an approved rider account.

## Notes

- This build is signed with the Vendo release key, so future versions install over it.
- Google sign-in is not enabled in this build; use email and password.
- No auto-update yet. Download the next release from the same link.
