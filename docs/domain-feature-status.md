# Mobile feature status

| Area | Current state | Remaining work |

| Rider registration | Refreshed four-step form still sends personal, Motorcycle/Van/L300/Truck vehicle, residence, and document data to the web API after six-digit email OTP or server-verified Google email proof. Orders without a Buyer pin have no destination marker. Road routing and turn-by-turn directions are not included. Actual destination receipt remains a Logistics web confirmation. Failed attempts and a broad offline queue remain open. |

Buyer app remains separate from this Rider integration. |
| Buyer home shell | Login now navigates to a new buyer `HomeScreen` with a branded header, search bar, category strip, deals banner, product grid, and a four-tab bottom navigation (Home, Categories, Cart, Profile).
