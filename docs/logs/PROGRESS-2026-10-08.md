- **Root cause:** Backend gap. The Laravel web app does not yet implement:
  - `POST /api/v1/rider/email/otp/send`  — accepts `{ email }`, sends 6-digit OTP
  - `POST /api/v1/rider/email/otp/verify` — accepts `{ email, code }`, returns `{ verification_token }`
- **Flutter side:** `rider_api.dart` `sendRegistrationCode()` and `verifyRegistrationCode()` are correctly implemented. No Flutter changes needed.
- **Action required (web repo):** Add the two routes above to the Laravel rider API. The verification token returned by the verify endpoint must be accepted by `POST /api/v1/rider/register`.
