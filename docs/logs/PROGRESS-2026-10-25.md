## Buyer home — full redesign (Shopee-inspired, Vendo-branded)

Rewrote `vendo_buyer/lib/features/home/screens/home_screen.dart` with a richer layout inspired by the Shopee mobile home and the Vendo web design. Shopee Live and Shopee Video were not included.

### Layout (top to bottom)
- **Sticky header bar** (pinned `SliverPersistentHeader`): purple gradient, Vendo logo-mark inside the search bar, search field, cart icon with badge, chat icon.
- **Quick-action strip**: five tappable icon tiles — Track Orders, Saved Items, Shops, Vouchers, Help.
- **Hero banner carousel** (`PageView`): three auto-swipeable branded banners (Welcome to Vendo, Deals of the Day, Free Delivery) with gradient background, decorative circles, bag icon, vendo chip, CTA button, and animated stretch-dot page indicator.
- **Trust badges row**: Cash on Delivery · Track Every Order · Approved Sellers · Chat With Sellers — four equal columns with icon + label.
- **Shop by Category**: 10 categories in circular-icon scrollable row matching the web catalog (Electronics, Women's/Men's Apparel, Kids & Baby, Home & Garden, Sports, Health & Beauty, Books, Food, Automotive).
- **Recommended for You**: 2-column product grid with image area placeholder, heart/save toggle, price in orange, star rating.
- **Jelly-pill bottom nav** unchanged.

### Structural changes
- `HomeScreen` now uses `IndexedStack` + `PopScope` (back button returns to Home tab before exiting) instead of a plain Column switch.
- `_HomeTab` promoted to `StatefulWidget` to own `PageController` for the banner carousel.
- Removed old `_Header`, `_CategoryChip`, `_CategoryItem`, `_ProductItem` classes; replaced with new purpose-built widgets.

### Changed files
- `vendo_buyer/lib/features/home/screens/home_screen.dart` (full rewrite)

### Known gaps
- All data (banners, categories, products) is static placeholder; no API is wired.
- Cart badge count is hardcoded to 0. Heart/save state is local only.
- No owner verification, build, or device walkthrough was run.
