# 6 November 2026

## Buyer: bottom navigation moved to its own file and restyled like the Rider bar

- Extracted the buyer bottom navigation out of `vendo_buyer/lib/features/home/screens/home_screen.dart` into `vendo_buyer/lib/features/home/widgets/buyer_nav_bar.dart` as the public `BuyerNavBar` widget. It keeps the four tabs (Home, Saves, Notification, Profile) and the same interface — `currentIndex` plus `onTap` — so the screen still owns the selected index, and the old private `_BottomNav`, `_NavColors`, `_NavItem`, `_PillShape` and `_NavButton` classes left `home_screen.dart`. The `dart:math` and `flutter/services` imports in `home_screen.dart` were only used by that code and were removed.
- Restyled the bar like the Rider dashboard's, per the request: it now floats — 16 px side margins, lifted 10 px off the bottom edge inside `SafeArea` — instead of being a sheet attached to the bottom. All four corners are rounded (36), the background is frosted glass (`BackdropFilter` blur, 70% white, thin border) over a soft drop shadow, matching the Rider bar.
- Kept the Rider motion and made the bounce more visible: one dark pill still stretches toward the tapped tab (leading edge eases out, trailing edge settles on an elastic curve) and squashes in mid-flight, and it now also hops up to 4 px during the trip before landing on the tab. The pill got a small shadow of its own.
- Behaviour unchanged: tapping the already-selected tab does nothing, a tab change still fires `HapticFeedback.selectionClick`, each tab is a `Semantics` button with `selected`, and the icon swaps with the existing 200 ms scale transition.
- Second pass on the request: the bar is now icons only. The visible Home / Saves / Notification / Profile labels were removed, leaving only `vPad` padding around the 32 px icon area, so the bar is 52 px tall instead of about 74; the names remain as each button's `Semantics` label for screen readers.
- Second pass, background: `HomeScreen`'s `Scaffold` now sets `extendBody: true`, so each tab's content continues behind the bar instead of stopping above it, and the glass was lightened from 70% to 60% white so the page shows through the 20 px blur. To keep the last row reachable, the new `kBuyerNavBarClearance` constant (78, plus the bottom safe-area inset) is added to the bottom padding of the Home scroll, the Saved grid and the Profile scroll. The pushed copy of Saved Items skips it because no bar covers that route.

**Changed files:** `vendo_buyer/lib/features/home/widgets/buyer_nav_bar.dart` (new), `vendo_buyer/lib/features/home/screens/home_screen.dart`, `vendo_buyer/lib/features/saved/screens/saved_screen.dart`, `vendo_buyer/lib/features/profile/screens/profile_screen.dart`, `docs/features/buyer-app.md`, `docs/domain-feature-status.md`.

**Known gaps:** `flutter analyze lib/features/home lib/features/saved lib/features/profile` reports no errors and no new warnings (only pre-existing `unnecessary_underscores` infos in `home_screen.dart`, `category_products_screen.dart` and `saved_screen.dart`). No device or emulator walkthrough was run, so the bounce timing, the blur on a real GPU, how readable the grey inactive icons are over busy product photos, and the clearance spacing are unverified; the owner performs that check. `docs/architecture.md` still calls `vendo_buyer` a prototype without a Buyer API in the paragraph that was already being edited in this working tree, so it was not touched here.
