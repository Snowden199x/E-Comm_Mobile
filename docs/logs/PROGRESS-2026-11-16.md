# Progress — 16 November 2026

## Rider earnings: return pickup label

- `vendo_rider/lib/features/dashboard/screens/earnings_screen.dart` now reads the API's `type` field. Rows with `type = return_pickup` show **Return pickup** with an assignment-return icon and "Collected from the buyer" instead of a hub position; the accrued summary adds the `summary.return_pickups` count when it is above zero. The section is now titled "Recent earnings".

## Mobile API networking: downloaded APKs work outside the LAN

- `vendo_buyer/lib/core/api/buyer_api.dart` no longer falls back to `http://192.168.1.17:8000/api/v1/buyer` in Android debug builds. The Buyer, Rider, and Driver API clients now default to their production `https://vendo-ph.app/api/v1/...` URL outside Linux debug builds.
- Release builds ignore a non-HTTPS `VENDO_API_BASE_URL` / `VENDO_BUYER_API_BASE_URL` override and fall back to production. This prevents a downloaded APK from being tied to `localhost`, `10.0.2.2`, or a private LAN address.
- `vendo_buyer/android/app/src/main/AndroidManifest.xml` now declares `INTERNET`, which the Buyer release APK needs to reach the API. The Buyer and Driver debug manifests permit cleartext HTTP for explicitly configured local development; release manifests remain HTTPS-only.
- Updated the Buyer, Rider integration, Driver, architecture, release, security, and status docs. Existing APKs must be rebuilt; no build, install, or network test was run in this session.
